# Operation

Run install.py without arguments to obtain the source bundle hash. Root installation requires --install --expected-sha256 HASH --state ABSOLUTE_EXTERNAL_STATE --device 2064. Use a separate state directory for this version. Root installer tests all 54 cases and validates the unit, source hashes and volume before starting the new service. It refuses to overwrite an existing deployment. No older service is changed.

Inspect systemctl status vivameda-crypto5m-study-v2.service and state/status.json. Active process, fresh capture writes, usable books, warmed reference history, exact opening anchor, forecasts, reservations, delayed fills and official settlement are separate checks. A running process alone proves none of the later checks.

Report: python3 -B report.py --state STATE. Capture integrity: capture.verify_capture(STATE/capture.sqlite3). Keep all raw records on the server; publish only generic acceptance summaries. Add STATE/STOP to stop new virtual attempts; retain inventory for resolution. Stop only this new unit to roll back operation; preserve state and v1.1. Never modify a pinned source or ledger in place. Review a new version for changes.

Reference failure: inspect reference_feed.error, raw point counts, latest_source_at and exact-opening skip reasons. The legacy endpoint can disappear. Do not remove freshness checks, invent an anchor or switch to Binance as a settlement proxy. Authenticated PolyBolt integration requires a separate reviewed adapter; it is not configured here.
